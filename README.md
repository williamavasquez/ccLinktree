# CC LinkTree

A modern, customizable LinkTree clone built with React, TypeScript, and Tailwind CSS. This application provides a beautiful, responsive landing page for artists and creators to share their links and social media profiles.

## Features

- Modern, responsive design with a gradient background
- Profile section with avatar and bio
- Customizable link cards with hover effects
- Social media integration
- Blur effects and modern UI components
- TypeScript for type safety
- Tailwind CSS for styling

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone [your-repo-url]
cd ccLinkTree
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

### Customization

To customize your LinkTree:

1. Update the profile information in `src/App.tsx`
2. Add your avatar and background images to the `public` folder
3. Customize the styling in `src/index.css`
4. Modify the link cards and social media links as needed
